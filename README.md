## 📖 How to read this portfolio

1. Open the relevant criterion folder using the links above.
2. Read the **criterion statement**, then the **evidence mapping** directly below it.
3. Check the referenced original evidence or public link to verify the claim.
4. Distinguish **documented outcomes** from **reported outcomes requiring corroboration**.

> **Confidentiality and verification:** Some underlying records contain private references, internal application information, review correspondence or identifying details. Their presence in the evidence inventory does **not** authorise public sharing. Restricted originals should be provided through an authorised private BCS channel, and any public copy should be disclosure-approved and adequately redacted. **An evidence description is not a substitute for the source record.**
